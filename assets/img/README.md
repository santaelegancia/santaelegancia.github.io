# Imagens

Nomes fixos esperados pelo site. Trocar o arquivo mantendo o nome não exige mexer no código.

| Arquivo | Uso | Observação |
| --- | --- | --- |
| `hero.jpg` | Hero | Retrato da Vanessa, vertical |
| `sobre.jpg` | Seção Sobre | Retrato ou foto de atendimento |
| `ebook.png` | Seção e-book | Capa do "Moda Descomplicada" |
| `logo.svg` | Header, rodapé, favicon | Vetorial |

Comprimir antes de subir (JPG ~200 KB no máximo por foto). Nunca fazer hotlink de imagens do site Framer.
